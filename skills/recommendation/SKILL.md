# 推荐输出（recommendation）

逐场推送 deep-analysis 的分析结果，最后发送汇总消息（默认附带胜负平 2 串 1 组合建议）。

**核心原则**：主人主玩「胜负平（1X2）」，以「胜负平 2 串 1」为主要组合方式。推荐输出以六列表首选/次选和点概率为主，汇总默认附带高概率与高确定性的 2 串 1 组合建议。同时保留真实交付链接（Polymarket）。独立泊松和比分只作分析依据，不默认推荐国内让球对冲。

## 输入

**交易交付核验（强制实网 Google 搜索 + Gamma API/BrowserOS neo 双重核验）**：生成表格前**必须先执行实网全网搜索**（`web_search(query='site:polymarket.com/event "主队英文" "客队英文"')` 或由 `BrowserOS neo` 直接在 `https://polymarket.com/sports` 搜索框检索）！利用搜索引擎自动完成中英文别名穿透与真实 URL/slug 定位；拿到 slug 后再调用 Gamma API 或 BrowserOS neo 核验最新实盘买卖价格（¢）与流动性。**严禁仅凭单一 API 调用或拼凑 slug 失败就草率谎称“未开放独立交易池”！** 只有当 Google 检索完全无对应比赛实体、且 BrowserOS neo 确认无池时，方可标注【Polymarket 未开放独立交易池】。按 `docs/Polymarket链接查找教程.md` 严格执行标准三步走。Gamma 展示价不当买入价；CLOB 按 `outcomes` 对应的 Yes 合约核最佳卖价、该价数量、买卖差与报价时点。无卖单写当前无可买报价；访问失败、未找到与确认未开盘分开。倍数只是未扣费用的条件总回收倍数，不保证成交。

来自 deep-analysis 的每场比赛综合评估结果。**执行 recommendation 时**，以收齐的 announce 所包含的**综合评估与 memory 摘要**为输入，**无需**再从 memory 读取 `## 深度分析`。

**资料闸门：亚盘/欧指时序空、只有体彩静态赔没有国际机构时序、或物理门禁返回非零退出码（exit 1） → 验收绝对不通过，严禁继续十步，严禁对外发布未过验场次！马上置顶发出严重警报并物理阻断。缺数据绝对禁止静默、绝对禁止跳过或无米之炊硬推。伤停未核实不是验收失败：贴页上原句后继续十步，未核实不得写成全主力。其他来源齐全且真实对得上可以通过。** **按本批实际分析场次数对齐逐场 `matchId` 与快照 SHA256 指纹：精选和候补都要有开球前实际发布版、首选/次选、胜/平/负点概率（无可靠估计写缺失）、三端裁决的关键反证、赔率报价公司与时间、市场逐家去水聚合口径、战意/伤停核实状态（未核实不得写成全主力），以及与盘赔推荐比分分开的独立泊松 λ/Top 6（未算就标未算）。**发布前核对第 3 列：首选与次选必须是两个不同结果（胜/平/负中的两项）。写成同一项视为单选，验收不通过，退回改次选后再发。深盘热门、体彩关闭基础胜平负（had=None）、口头「无悬念做胆」均不得例外。**记录每场哪些证据已验、哪些未验，必须绑定物理快照文件的 SHA256 校验指纹（前 8 位）；不能只填“验收通过”，也不能把推荐比分充当泊松 Top 6。发布时锁定实际发布时间与引用的分析版本，已发布记录不可事后补值伪装赛前证据。**交易价值与赛果首选分开，市场排序不替代裁决。发现泄漏、越界、无依据参数、克隆造假或结论冲突时返回具体修正点；无法修复则披露未通过及可用部分，不发布成合格盲测或能力提升证据。验收是资料与交付真实性检查，不新增赔率阈值门禁；不要求每场重读全部论文。

**流程衔接说明**：

- **编排/多场场景**（赛前全流程、手动多场分析、精选多场）：**单场worker完成10步后先回传待验收报告及证据**，worker不先行对外发布。主会话／编排收齐后验收本批场次，先保存本批全部实际分析摘要与契约卡，再逐场交付六列表。recommendation一次执行精选（步骤2）→ 胜平负汇总（含 2 串 1 组合，步骤3）→ 按步骤5保存待发布版 → 步骤4交付并回填投递状态。
- **单场场景**：单场 worker 完成后主会话收齐 announce，再执行 recommendation（精选 1 场、汇总、写 memory）。
- 上述任一场景下，**初筛通过 0 场**时无深度分析输入，recommendation 仍须执行（见下）。

**初筛通过 0 场时**：无深度分析输入，recommendation 仍须执行——生成一条汇总消息（今日无候选场次，无推荐），写入 `## 推荐` 并推送给主人，以便 Heartbeat 与流程状态一致。

## 执行步骤

**当深度分析场次为 0 时**（对应窗口初筛通过 0 场）：跳过步骤 1–3，直接生成一条汇总消息「本窗口无候选场次，无推荐」，先写入该窗口 `## 推荐` 再交付（精选 0 场、无串关），然后结束。早盘零候选只结束早盘，不短路晚盘。推送消息可带一句「⏳ 今日体彩销售窗口至：{22:00/23:00}（线上 Polymarket 与线下实体店双轨兼顾）」。**写入的 `## 推荐` 仍按步骤 5 的标准结构**（含 ### 精选场次、### 候补场次、### 串关组合）。精选/候补表无数据行。失败空返回的赛程不得走此零场分支。

### 步骤 1：逐场推送分析报告（内容格式规范）

**编排/多场场景下**：单场报告验收后已逐场发布的，不重复发送；未验收或未发布的先完成回传验收，再进入步骤 2（精选）。

**非编排或需本 skill 输出单场时**：分析完一场先验收并按步骤 5 保存该场待发布版本，再按步骤 4 交付，不等全部分析完。主人可以边看边决策。以下为单场报告的内容与格式规范。

**默认交付**：验收后只发七列表（场次/时间、对阵双方、胜负平、让球、胜/平/负点概率（OO-EPC去水）、庄家诱盘破译、Polymarket 真实链接）。第 3 列只放首选/次选且不折行。第 4 列为体彩让球推荐，必须标注官方让球数（快照 `sporttery.letBall` 如 `[-1]` 或 `[+1]`，严禁幻觉）与物理三维推演（净胜球）自然解算出的推荐选项（如 `[-1] 让平（次选让负）` 或 `[+1] 让胜`），与胜负平完全自洽闭环。第 5 列只放三个百分比点概率（统一格式如：胜 XX.X% / 平 XX.X% / 负 XX.X%，严禁直接显示 0.xx 小数，直观呈现胜平负概率结构）或缺失说明。单元格须标明实际方法：已执行 OO-EPC 才可按该方法填写；未执行则直写未执行，另列比例法时只标比例法市场参考。禁止借表头把综合判断包装成 OO-EPC。禁止把第 3 列写成「终审人话指令」。禁止把第 5 列写成「真实赛果剧本」。以下长模板仅供明确要求详细报告时使用；完整十步必须执行，未要求过程不自动发送第二条。

扩展分析或明确请求其他玩法时的表述规范（不改变默认六列表）：

- **编号**：来自初筛或当日赛程；主人直接指定比赛 ID/URL 时可能无编号，填「-」即可。
- **分析报价（证据必留）**：亚盘即时盘口与主客水、欧指完整三项及报价时点保存在后台分析证据；不是主人可执行的Polymarket买入价。明确要求展开时可展示，交易报价按输入节另核CLOB。
- 胜平负：保留首选＋次选格式，**首选继承deep-analysis第7—9步完成让球/RLM与三端裁决后的结论**，次选按原交叉依据给出；汇总不退回仅看欧指。现有命中账按原口径，新研究另列首选正确与双选覆盖，不把覆盖当单选准确率。
- 亚盘：「主队让{X}球 主胜」「主队受让{X}球 主胜」；方向不明确时标「⚠️ 观望」
- 大小球：改为 **首选 + 次选** 两档盘口：`首选 大/小 X 球；次选 大/小 Y 球`（盘口：X/Y，预期总进球：λ1+λ2）。次选用于覆盖/风控；方向不明确或与泊松比分重大矛盾时标「⚠️观望」。
- 比分：「比分 X:X」
- **两套比分（deep-analysis 矛盾场次）**：当 deep-analysis 输出了两套比分（整体 Top 3 + 与大小球同方向 Top 3）时，recommendation 的汇总表「比分」列默认填整体 Top 3；同时在该场的「核心矛盾」或「理由」中补一句「本场存在大小球 vs 泊松比分矛盾，另有同方向 Top 3 参考」。

**玩法与统计范围**：默认只推荐 Polymarket 胜平负，亚盘、大小球和比分是分析依据，不自动计为投注推荐。只有主人明确请求并在赛前实际发布的其他玩法，才按对应口径独立评分；标注观望的玩法不计入推荐命中统计。历史多玩法账保留原口径，不重算。首选命中、双选覆盖与独立泊松分别记录，不能互相替代。

**逐场推送**：每场报告由主会话/编排完成回传验收，且本批全部实际分析摘要和契约卡已保存后推送；未验收或本批保存未完成不对外发布。

**消息长度控制**：单条消息如超过 4000 字符，拆分为多条顺序发送（飞书等通讯渠道有长度限制）：

- **逐场分析报告**：本批全部实际分析摘要及契约卡已保存后，默认只发六列表卡片及胜/平/负点概率；若主人明确要求查看过程，再按「先结论后过程」拆条发送（首条末尾「⬇️ 接下文」，续条开头「⬆️ 接上文」）。
- 汇总消息：如超长，按「精选推荐表（含 2 串 1 组合）」和「候补/观察 + 风险提示」拆条

### 步骤 2：精选与全量汇总（全部分析完成后执行）

全部场次深度分析完成后，对所有已分析场次进行全量推演汇总（全量呈现，不人为截断丢弃；按信心度与做市商确定性明确标注评级）。

**精选与排序规则**：

1. **信心度为「低」或证据严重打架的场次** → 标注为「⚠️ 观望/防冷」
2. 对信心度「高」和「中」的场次，按以下优先级综合排序：
   - 信心度（高 > 中）
   - 串关适合度（🔒做胆 > ✅可串 > ⚠️慎串）
   - 胜平负三端证据充分度、跨市场一致性与未决矛盾；比分 Top 1 只作辅助参考，不替代胜平负判断
   - 联赛层级（高 > 中）
3. 汇总表全量呈现所有已分析比赛，前排优先作为核心做胆推荐，其余场次作为可串或博高赔补充，不人为截断。

**数量控制**：

- **全量开售场次排队全覆盖纪律（严禁擅自截断）**：严格遵循 `MAX_DAILY_ANALYSIS: ALL` 与 `ELITE_DAILY: ALL`。当期窗口（如晚盘 14 场）所有开售比赛必须全量完成推演并输出至表格，严禁任何 AI 借口“精选2-3场”擅自截断或只推第一批！开售多场时排队分批全量推完交付；
- 主人说「只要 1 场最稳的」→ 标出 1 场顶级核心胆材
- 如果所有场次信心度都低 → 如实告知「今日无高信心推荐，客观证据打架，建议观望（注：若存在数据缺失则必须置顶报警，严禁借观望掩饰缺口）」
