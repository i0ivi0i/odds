# 深度分析推送通知模板

供 agent 严格按此结构推送单场分析报告；主人可据此检查是否缺项、是否按模板执行。

---

## 一、推送结构总览

**必须先按 `skills/deep-analysis/SKILL.md` 完成全部 10 步分析，再生成综合评估**，之后才组稿推送。分析执行顺序与消息展示顺序不同：执行时从基本面到风险，推送时先结论、后过程。若总字符数 **超过 4000**（飞书等渠道有长度限制），须分段发送，不得为省字数省略必含块或步骤。

- **分段方式**：第 1 条＝「━━━ 结论 ━━━」（建议 ≤3500 字），后续条＝「━━━ 分析过程 ━━━」；过程按 4000 字继续拆条。
- **衔接**：首条末尾加「⬇️ 接下文」，续条开头加「⬆️ 接上文」。
- **每段开头**（可选，便于飞书等折叠）：`【深度分析 {编号} 第 N 段/共 M 段】`

---

## 二、必含块（下列按编写顺序列出，发送时先结论、后过程）

### 1. 标题与场次信息（首段开头）

```
【深度分析 {编号} 第 1 段/共 M 段】
📊 深度分析 [{联赛}] {主队} VS {客队}
🆔 比赛 ID: {matchId} | 竞彩编号：{编号}
⏰ 开球：{YYYY-MM-DD HH:mm} | 🏟️ {球场} | 天气：{可选}
```

### 2. 分析过程（结论之后发送，可多段）

- **第 1 步：基本面**（近况、主客场、交锋等背景；单列「战意核实」：赛制与积分需求、实际投入、证据及盘口响应，不由“必须赢”推成“会赢”）
- **第 2 步：伤停**（独立重点：双方缺阵／停赛、首发与替补、轮换的实际影响；注明来源和时点，缺失如实标注）
- **第 3 步：泊松基准**（基于基本面与伤停，输出预期进球与泊松整体 Top 4～6；此时不提前引用盘赔结论，自开盘不参与分析依据）
- **第 4 步：欧指分析**
  - **欧指赔率变动轨迹分析（必做）**：
    - 时点对齐表（初盘 / T1 时间 / T2 时间 / … / 即时盘，各公司主/平/客）。**时点格式**：初盘/即时盘不标时间；T1、T2、… 为共同时点，时间用 `MM-DD HH:mm`（如 T1 03-15 12:30）或同场简写 `HH:mm`（如 T1 12:30），与步骤 1.5 抓取的「变化时间」一致。
    - 每家意图小结（除平博）
    - 相同时点交叉认证
    - 一句话解读
  - 六层排查小结
- **第 5 步：亚盘分析**
  - **亚盘赔率变动轨迹分析（必做）**：
    - 时点对齐表（初盘 / T1 / T2 / … / 即时盘，各公司 盘口/主水/客水）；时点含义与格式同第 4 步。
    - 每家意图小结（除平博）
    - 相同时点交叉认证
    - 一句话解读
  - 六层排查小结
- **第 6 步：大小球**
  - **大小球赔率变动轨迹分析（必做）**：
    - 时点对齐表（时点格式同第 4 步）、每家意图、相同时点认证、一句话解读
  - 小结：写**首选 + 次选**两档盘口（如「首选 大 3；次选 大 2.5」或「首选 小 2.5；次选 小 3」），再写预期总进球
- **第 7 步：赔率合理性评估**（基本面、泊松与三类盘赔对照，列清具体矛盾）
- **第 8 步：赔率变动解读**（跨欧指/亚盘/大小球综合时间线，不省略此环节）
- **第 9 步：关键点 / 疑点 / 矛盾分析**（先写胜/平/负三端，再归纳关键点、疑点与矛盾）
- **第 10 步：风险提示**（本场专项风险在前，通用风险在后）

十步完成后生成「输出 1：综合评估与推荐」，不是把综合评估算作第 10 步；读盘心法贯穿各步，不替代十步。

若分析过程超过 4000 字，在过程内部拆条，并加 ⬇️ 接下文 / ⬆️ 接上文。

### 3. 结论（生成在十步之后，发送在第 1 段，必须含以下全部）

```

🎯 推荐：
  ⚽ 胜平负：{主胜/平局/客胜}（或主结论 + 备选）

```

## 三、检查清单（主人/复盘用）

- [ ] 编号、比赛ID、开球时间 在结论段**第一行**出现
- [ ] 战意单列核实、伤停独立展示，二者注明来源及时点；信息缺失保留为不确定项，不写成已确认无影响
- [ ] 第 3 步先出 **泊松基准**，仅依赖基本面与伤停；后续市场锚定不得冒充原始基准
- [ ] 第 4 步含 **欧指赔率变动轨迹**：时点表 + 每家意图 + 相同时点认证 + 一句话解读
- [ ] 第 5 步含 **亚盘赔率变动轨迹**：时点表 + 每家意图 + 相同时点认证 + 一句话解读
- [ ] 第 6 步含 **大小球赔率变动轨迹**：时点表 + 每家意图 + 相同时点认证 + 一句话解读
- [ ] 第 7～10 步逐项展示合理性、变动、关键点/疑点/矛盾、风险，综合评估在十步完成后生成
- [ ] 按 `docs/论文/README.md` 在实际步骤执行适用方法：多公司逐家去水、分歧与时点、AH退本结算、总进球与净胜球相容性；无数据注明缺口，不逐篇打卡
- [ ] 赛前首选与三个点概率、来源、发布版本和赔率截至时点已留存；单选与覆盖分开，庄家解释是可推翻假设不是已知账本
- [ ] 结论段含 胜平负/亚盘/大小球/比分、关键点/疑点/核心矛盾、信心度、串关适合度、风险
- [ ] 单条消息 ≤ 4000 字；超则分段并带 ⬇️/⬆️
