# 复盘论文（本项目）

比赛战报仍在 `data/`。这里只放「怎么复盘才不会拿一场比分改规矩」的原文。

用法就三句：先遮比分审当时理由；看整份胜/平/负概率，不当对错本；改规矩必须用后面没见过的球检验。论文指导方法，不证明本项目能赚钱。
