# ADR 0002: 双锁博弈推演架构（防书呆子教条 ＋ 防主观臆测）

## 状态 (Status)
已采纳 / 执行中 (Accepted)

## 决策背景 (Context)
在体育博彩预测体系中，常见的两大毁灭性极端是：
1. **书呆子教条陷阱 (Dogmatic Bookworm)**：盲目神化学术论文或数学公式，认为算个泊松比分或去水胜率就能预测比赛，忽视了博彩公司作为自营博弈方“少赔多赚、极小化最大损失”的利益本质。
2. **主观神棍猜想陷阱 (Subjective Guesswork)**：脱离客观数据支撑，仅凭“我觉得要爆冷”、“名气大应该赢”等主观感觉与玄学直觉下结论。

主人明确指示必须采取 **“A + B” 辩证合体架构**：既要死磕庄家博弈的第一性原理，又要保持数学与物理数据的绝对严密，两手都要硬！

## 决策内容 (Decision)
确立 **“双锁闭环推演架构 (Dual-Lock Actuarial Synthesis)”** 作为全局推演的不可动摇法则：

### 第一道锁：数学与客观数据基线 (Lock 1 - Quantitative Baseline)
- **拒绝拍脑袋**：推演必须以 15 篇论文的科学算法为底座（去水真实胜率、进球数泊松分布、伤停攻防动态衰减）。
- **零凭证否决**：凡无客观数据支持的“直觉”、“感觉”、“可能”，一律禁止作为推演依据。

### 第二道锁：庄家博弈与逆向破译 (Lock 2 - Bookmaker Reverse Engineering)
- **拒绝教条公式**：时刻牢记赔率是庄家调配资金、诱导大众的杠杆，而非物理概率。
- **初盘为底牌**：以无污染初始盘口界定真实期望值；从初盘至临盘的时序变化中，以“极小化净赔付（少赔多赚）”反推庄家真实防范底线。

### 裁决准则：双路证据闭环 (Synthesis Gate)
给出最终胜平负结论前，必须满足：
$$\text{推演结论} = \text{客观数据基准 (Lock 1)} \bigcap \text{庄家操盘意图 (Lock 2)}$$
1. **若两锁一致**：数据支持且庄家在真实防守，确认为高确定性做胆目标；
2. **若两锁背离**：数据看好但庄家高挂诱买，强制判定为诱盘陷阱，反打冷门或观望；
3. **证据要求**：定性必须具备双路独立物理证据（盘口水位变动 ＋ 跨市场背离），缺一不可。

## 收益与代价 (Consequences)
- **收益**：既消灭了公式教条主义，又杜绝了主观玄学胡猜，形成真正兼具科学性与实战杀伤力的顶尖量化决策机器。
- **代价**：推演工序更加严苛，每一场必须同时过堂数学与博弈双重考验。
