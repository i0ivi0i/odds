# OO-EPC 去水计算与推演应用手册（大模型推演教学指南）

本文档是系统内所有 AI 智能体（主会话、编排智能体、单场深度分析 Worker）在执行足球倍率推演时的**标准操作手册与思维链教学指南**。
核心目标：**彻底消除大模型心算与概率捏造，教会大模型如何调用纯数学算法并将其深度融入十步推演与三端落槌。**

---

## 一、为什么绝对禁止大模型心算？（历史教训）

### 1. 大模型心算的系统性弊端
大语言模型本质是概率文本生成器，不具备高精度浮点数数学计算能力。当大模型在推演中尝试“心算”去水概率时，必然产生两种致命偏差：
1. **迎合偏见（Confirmation Bias）**：为了迎合自己初步看好的赛果，心理暗示性地捏造虚高概率（例如历史实战中，威廉希尔真实去水平率只有 31.6%，大模型心算时为了推荐平局，凭空捏造为 37.0%）。
2. **长尾冷门低估（FLB 盲区）**：忽视长尾标准误差扩散，无法准确计算深盘热门与高赔冷门的非对称抽水。

### 2. 官方标准：东京大学 Goto (2026) OO-EPC
本系统统一采用东京大学 Shota Goto (2026) 官方开源标准算法（Equal-Profitability Confidence）：
- 抽水扣除并非简单等比均摊，而是根据各选项标准误差 $SE = \sqrt{1 - \pi_i}$ 进行等置信回退扣减；
- 庄家在低赔稳胆上承担的方差极小，在长尾冷门上承担的方差极大；
- 扣减后的概率严格满足全概率公理（和严格为 1.000000）。

- **调用时机**：在 `skills/deep-analysis/SKILL.md` 的**第 4 步（欧洲指数分析）**中，提取分析依据公司（欧洲赛事看威廉/立博/365/平博，亚洲赛事看澳彩/皇冠/易胜博）的初盘和即时盘后立即调用。

### 2. 命令行调用语法

#### ① 标准三项欧指去水（获取结构化 JSON）
```bash
python 算法/src/adapter/cli.py <主胜赔> <平局赔> <客胜赔> --json
```

**实战范例**：
对威廉希尔初盘 `2.10 / 3.40 / 3.55`：
```bash
python 算法/src/adapter/cli.py 2.10 3.40 3.55 --json
```

## 三、大模型如何消化与解读计算结果（思维链教学）

拿到 `cli.py` 返回的 JSON 之后，大模型必须按以下四步思维链进行深度博弈解读，不得停留在抄数字层面：

### 教学 1：解读 `margin`（庄家总水钱抽水）
- **常规联赛公认水钱**：主流欧洲五大联赛欧指抽水一般在 `4.0% ~ 6.5%`（`margin` 介于 0.040 ~ 0.065）；
- **风控防守信号**：若某场比赛抽水异常高达 `8% ~ 10%+`，说明庄家对该场比赛信息透明度存疑，显著提高了全盘防守溢价，需降低推演信心或寻找大冷门。

### 教学 2：四项论文质问反审（破除散户稳胆偏见）
在执行五步认知闭环的“四项论文质问之二（Goto 质问）”时，将大模型最初的主观直觉与真实计算结果对照：
- **典型误区**：散户看到主胜 2.10，直觉以为主队稳操胜券（>50%）；
- **客观现实**：去水后无偏胜率仅为 `46.06%`，而平负合计概率高达 `53.94%`！平局概率高达 `27.60%`；
- **纠偏动作**：大模型必须反思“主队真实胜率未过半，是否盲信了豪门名气？如果让球盘还要让半球，主队拿下的门槛是否被严重高估？”

### 教学 3：欧亚双盘背离验真（Constantinou 质问）
将 OO-EPC 去水胜率与亚盘盘口门槛进行几何比对：
- **标准折合关系**：
  - 去水胜率 `45% ~ 48%`：合理盘口应为 **平手低水** 或 **平/半高水**（净胜 1 球赢全，打平输半）；
  - 去水胜率 `50% ~ 55%`：合理盘口应为 **半球中低水**（打平全输，必须赢球才能赢盘）；
- **背离破译（庄家出货 vs 真实防守）**：
  - 若 OO-EPC 去水主胜只有 `46%`，但亚盘强行开出 **半球低水（甚至半/一）**，且欧指持续小降主胜：
    👉 **破译结论**：欧指通过降水营造强队稳胜假象（引流散户），而亚盘门槛过高、拒绝阻热，存在极大出货诱买嫌疑！防守底线在受让方或平局。

### 教学 4：与独立泊松进球分布交叉验证
- 将 OO-EPC 去水胜率（资金盘口视角）与独立泊松模型胜率（历史物理进球视角）比对：
  - 若两者一致（如泊松胜率 47%，OO-EPC 胜率 46%）：说明盘口完全反映两队真实竞技实力，无过度做市；
  - 若两者严重背离（如泊松胜率仅 32%，但盘口去水胜率被买到 48%）：必须排查核心伤停复出、战意倾斜，或警惕机构刻意造热。

### 2. 深度分析结构化摘要与【认知契约卡】
```markdown
- 胜平负点概率：胜 0.46 / 平 0.28 / 负 0.26（来源：威廉希尔初盘 OO-EPC 纯数学去水计算）
- 【认知契约卡】：
  - 选择与排除依据：威廉初盘 OO-EPC 无偏胜率仅 46.06%，亚盘强让半球属于浅盘深开；排除主胜深盘打穿可能
  - 关键拍板依据：OO-EPC 平率 27.60% 高于散户认知，机构客赔 3.55 长期阻热
  - 庄家博弈假说与竞争解释：假说为利用豪门关注度在胜平负主胜诱买，真实防守在受让平负
  - 可推翻反证与改变条件：若临场立博主胜跌破 1.95 且亚盘升半/一低水，则诱买假说推翻
```
