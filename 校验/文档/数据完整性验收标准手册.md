# 数据完整性检验与验收标准手册

本手册是整个足球倍率推演系统的数据质量宪法。
所有赛前深度推演、Worker 任务执行与自动化流程，在开启 10 步分析前必须以本手册为法定基准，通过物理安检工具获得通行证明。

---

## 一、为什么需要物理数据安检？

大模型存在生成式幻觉与偷懒本能。当球探网快照由于网络掐断、握手超时或加载不全而出现残缺时，大模型常倾向于虚构“机构中盘降水”、“主力全部出战”等假数据糊弄推演。
**垃圾数据进入，只能推演出毒药赛果。**
因此，推演前必须物理运行：
```bash
python 校验/src/adapter/cli.py --match data/YYYY-MM-DD/{matchId}.json
```
若命令退出码为 `1`（FAIL），推演**立即物理熔断**，绝不妥协。

## 二、8 大黄金维度法定验收规则

### 1. 基础战绩与攻防进失球维度 (BASIC_STATS)
- **验收目标**：主客队名称、所属联赛，以及近 6 场进失球、主客场进失球物理硬核统计。
- **合格标准**：`match.homeTeam`、`match.awayTeam`、`match.league` 齐全，且必须具备真实的进失球数字（如 `homeGoals` / `awayGoals` / `basicStatsText` 中包含真实进失球）。
- **熔断表现**：若缺少进失球硬核数字，直接报 `FAIL` 熔断阻断。

### 2. 欧洲指数 (1X2) 维度 (EUROPE_1X2)
- **验收目标**：欧洲百家初即盘、威廉希尔、立博、Bet365 等欧指数据。
- **合格标准**：`european1x2Text` 或 `markets.europeHistories` 包含有效初盘与即时盘。
- **熔断表现**：无欧指数据直接 `FAIL` 熔断。

### 3. 亚洲让球盘 (AH) 维度 (ASIAN_HANDICAP)
- **验收目标**：澳彩、皇冠、365、易胜博四家主流亚洲让球盘口与两端水位。
- **合格标准**：`asianOddsText` 或 `markets.asianHistories` 包含主流机构让球数据。
- **熔断表现**：无主流让球盘直接 `FAIL` 熔断。

### 4. 大小球进球数 (OU) 维度 (OVER_UNDER)
- **验收目标**：主流四家大小球初盘与即时盘口档位、大球水与小球水。
- **合格标准**：`overUnderText` 或 `markets.overUnderHistories` 包含主流进球数盘口。
- **熔断表现**：无大小球盘口直接 `FAIL` 熔断。

### 5. 分钟级变盘流水时序维度 (TREND_HISTORY) - 【核心防假赛与假摔】
- **验收目标**：开盘至赛前的升降盘与水位变动全周期分秒级时序记录。
- **合格标准**：
  - 变盘流水必须包含明确的月份-日期及分秒时间戳（如 `10-07 21:33`）；
  - 有效时间戳记录总数**必须 $\ge 6$ 条**！
  - 严禁仅拿静态初盘和即时盘两行冒充时序。
- **熔断表现**：缺少时间戳或记录 $< 6$ 行时，直接判为严重时序残缺，**强制退出码 1 阻断推演**。

### 6. Crown 皇冠全指数波胆维度 (CROWN_CORRECT_SCORE)
- **验收目标**：0:0 至 4:4 精确波胆赔率矩阵（独家精算核心输入）。
- **合格标准**：`correctScoreOdds` 包含有效比分赔率矩阵，或 `markets.crowFullIndex` 结构化字段完整。
- **熔断表现**：无波胆数据直接 `FAIL` 熔断。

### 7. 微观阵容与首发伤停真实性 (LINEUP_INJURY)
- **合格标准**：必须包含结构化球员姓名、球衣号/位置及具体医学伤停原因（如韧带、拉伤、红牌等）；或者球探网官方注明“暂无数据”。
- **熔断表现**：严禁用主观概括套话（如“主力阵容齐整无伤病”、“战意强烈全员健康出战”）冒充伤停，检测到套话直接报 `FAIL` 熔断阻断！
- **法定容错**：若官方确实为“暂无数据”，判定为 `WARN`（警告），允许推演但必须置顶提醒未核实。

### 8. Polymarket 预测市场真实流动性 (POLYMARKET_LIQUIDITY)
- **合格标准**：若有真实独立交易池，填写真实可点击 URL；若未开放独立交易池或成交量为零，必须如实标明【平台未开放交易池/暂无流动性】。
- **熔断表现**：严禁用模板占位符（如 `{slug}`、`{league}`）编造虚假 URL，检测到伪造链接直接 `FAIL` 熔断！

## 三、算法工具命令行调用速查

推演中的数学计算与安检必须调用纯 Python 物理工具，严禁大模型心算脑补：

```bash
# 1. 赔率去水 (Goto OO-EPC 官方标准，获取去水无偏概率)
python 算法/src/adapter/cli.py 2.10 3.00 3.50 --json

# 2. 泊松进球期望值与 Top 6 比分分布计算 (输入主客λ，零偏差确定性输出)
python 算法/src/adapter/cli.py --poisson 1.50 1.20 --json

# 3. 单场比赛安检 (控制台可读排版，8 大维度物理守门)
python 校验/src/adapter/cli.py --match data/YYYY-MM-DD/{matchId}.json

# 4. 单场比赛安检 (机器可读 JSON 法定收据)
python 校验/src/adapter/cli.py --match data/YYYY-MM-DD/{matchId}.json --json

# 5. 全库系统规范与图谱健康巡检
python 校验/src/adapter/cli.py --system
```
